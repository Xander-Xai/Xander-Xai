## How I build · 我的实践方式

```text
Curiosity / Real problem
       ↓
Research & small experiments
       ↓
Working prototype
       ↓
Tests, evaluation & evidence
       ↓
Documentation & open sharing
       ↓
Feedback → next iteration
```

I value **clear problem framing, reproducible results, honest limitations, and useful artifacts**. A working prototype is a step forward; a verified, maintainable project is a different milestone.
